# Плейтест «Плота на порогах»: что проверить в Studio

30–40 минут. Порядок: запуск → честный заплыв → вдвоём → магазин → отладка.

## 0. Запуск (5 мин)
```powershell
git pull
rokit install
rojo build -o game.rbxl
```
Открой `game.rbxl`, **View → Output**, **Play** (F5).
- [ ] Персонаж появляется на причале через 1–3 с (мир строится до появления).
- [ ] В Output нет красных строк. Строка `[World] built in N s` — запиши N.
- [ ] Через ~5 с: `[SELFTEST] RESULT N/N passed`. Ожидаемые WARN: `products configured` (ID = 0) и `player data saves` (если не включён доступ к API).

## 1. Честный заплыв в одиночку (10 мин)
| Момент | Проверь |
|---|---|
| Причал | Плот качается у причала, видна табличка «плот · встань на палубу». Можно ли зайти с причала через проход в правом леере? |
| На палубе | Справа внизу схема плота с твоей золотой точкой; кольцо центра масс двигается, когда ходишь. Отсчёт «Отплытие через 3» (один на сервере — короткий). |
| Отплытие | Персонаж **едет вместе с плотом**, не соскальзывает. Камера не дёргается. |
| Причал → перекаты | Таблички «встань у правого/левого борта». Встал справа — плот ушёл вправо и собрал монеты. **Достаточно ли быстро реагирует?** |
| Камни | Удар трясёт камеру и пишет «−N». Видна пена вокруг камней. |
| Каньон | Ворота с буями и жёлтой перекладиной; «Ворота! +3». |
| Омут | Полосы пены крутятся. Попав в воронку, плот тормозит и тянет в центр; все к борту — вырываешься. |
| «Зубы» | Быстро и тесно, но проходимо? Золотые монеты у камней — соблазн? |
| Водопад | За ~150 studs крупно мигает «ВСЕ НА КОРМУ!». На корме — «Чистая посадка», на носу — «−30». Персонаж не улетает с плота при падении. |
| Озеро | Финишная арка, окно итогов: время, монеты, ворота, рекорд. Через 6 с ты на причале. |
| Выпал за борт | Прыгни в воду: через 1,5 с вернёт на палубу с тостом. |

## 2. Вдвоём (5 мин)
**Test → Clients and Servers** (раздел), 2 игрока → **Start**.
- [ ] Оба на палубе → отсчёт 3 с. Капитан — кто взошёл первым (его раскраска плота).
- [ ] Встаньте у разных бортов — плот идёт прямо (кольцо в центре). У одного — уходит вбок.
- [ ] Тост «Экипаж 2: монеты ×1.15».
- [ ] Второй плот появляется у причала через 3 с после отплытия первого.

## 3. Магазин и покупки (10 мин)
- [ ] Кнопка «Магазин» и сундук на причале (подсказка «Магазин») открывают одно и то же.
- [ ] **Косметика:** DBG → «+1000 coins», купи «Лаймовый жилет» — жилет на персонаже сменился. «R$ 49» у редкого предмета → тост «Studio: покупка эмулирована», предмет твой.
- [ ] **Сундук:** у каждого предмета процент, сверху — проценты редкостей (60 / 28 / 10 / 2). «Открыть» → окно с выпавшим предметом; дубликат пишет «+N монет».
- [ ] **Пропуска:** VIP → золотая табличка над головой, в косметике доступны золотые жилет и плот. «Прочный плот» → на следующем заплыве прочность 150.
- [ ] **Второй шанс:** DBG → «Hull → 1», врежься в берег. Окно «Плот разбит!» с таймером 10 с. «Второй шанс» → плот 50/100 и плывёт. Без покупки — плот разваливается, ты на причале, итоги «Плот не дошёл».
- [ ] Шрифт и кнопки читаются на маленьком экране: **Test → Device** (эмулятор телефона). Схема веса не закрывает кнопку прыжка.

## 4. Отладка (5 мин)
Кнопка **DBG** справа сверху:
- [ ] Autopilot — плот сам проходит реку без ударов (так играет внимательный экипаж).
- [ ] → Canyon / Whirlpool / Teeth / Waterfall — переносит плот вместе с экипажем.
- [ ] RU / EN — все тексты, таблички на берегу и подсказки переводятся.
- [ ] Self-test — строки `[SELFTEST]` в Output.
- [ ] FPS (**View → Stats** или Ctrl+Shift+F5) на перекатах и на озере.

## Как прислать обратную связь
```
Мир строится: __ с, FPS: __
SELFTEST: (строки с FAIL/WARN)
Красные строки из Output: (если есть)
Плот везёт персонажа: да / соскальзывает / дёргается
Руление весом: слишком резко / нормально / вяло
Сложность: перекаты __, каньон __, омут __, «зубы» __, водопад __ (легко/норм/тяжело)
Время заплыва: __, монет за заплыв: __
Что непонятно новичку:
Что сломано:
```
